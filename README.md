# Basecamp Desk

Landing page and free client-side tools for Basecamp Desk, AI drafting kits for small outdoor, tour, and guide businesses. Served with GitHub Pages from the `main` branch.

- `index.html`: Landing page with interactive trap comparisons and waitlist form (set `WAITLIST_ENDPOINT` to connect Kit/Formspree)
- `workbench.html`: Client-side Business Fact Sheet Builder and Review Reply Desk prompt assembler with local PII scrubber
- `season-check.html`: Zero-upload in-browser booking export PII scrubber and deterministic YoY reconciler
- `privacy.html`: Plain-English privacy policy for the web tools and Guest Reply Desk Chrome extension
- `styles.css`: Shared stylesheet with light/dark theme support and print-to-PDF rules
- `downloads/`: Raw Markdown downloads for the free Review Reply Desk and Business Fact Sheet

Paid kits are not in this repository.
